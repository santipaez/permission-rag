# Product roadmap 2027

The roadmap is organised by outcome, not by feature. Each outcome names the
metric that moves and the team that owns it.

## First half

The internal operations platform absorbs case management and retires the manual
spreadsheet that currently feeds the weekly report. Success is measured by the
number of reports produced without human assembly, which should go from zero to
eighty percent.

## Second half

The assistant becomes the primary way people query operational data. The measure
is the share of questions answered without opening a dashboard. Anything below
forty percent by the end of the third quarter triggers a redesign, not more
prompt tuning.

## Deliberately not doing

No public API this year. No mobile application. Both were considered and both
lose to the assistant bet, because the assistant multiplies every existing
workflow while an API only serves the teams that already have engineers.
