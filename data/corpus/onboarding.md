# New starter onboarding

Day one starts with the identity handover. The hiring manager opens a ticket in
the service desk asking for a Microsoft Entra ID account, a licence assignment
and the correct security group. Nobody gets access before that ticket exists.

The first week has three checkpoints. On day one the account is provisioned and
the laptop is enrolled in Intune. By day three the new starter has completed the
security awareness module. By day five they have a buddy and their first
delivery ticket assigned.

## Access rules

Access is granted by group, never per person. If a new starter needs a resource
that no group covers, the group is created first and the resource is attached to
it. Exceptions expire after thirty days and must be renewed in writing.

## Equipment

Laptops ship with Windows Autopilot. The device registers on first boot, the
standard applications install themselves and the drive is encrypted before the
user signs in. Devices that fail enrolment go back to the service desk rather
than being repaired by hand.

## Escalation

If provisioning stalls for more than two business days, the hiring manager
contacts the service desk lead directly. Stalled onboarding is tracked as an
incident, not as a request, because it blocks a person from working.
